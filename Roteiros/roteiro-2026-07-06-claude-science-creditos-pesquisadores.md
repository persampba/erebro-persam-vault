## Introdução (30s–2min)

**[Contexto]**

Na semana do triplo evento da Anthropic — Claude Sonnet 5, Fable 5 voltando e Claude Science — o que passou mais despercebido foi exatamente o que tem a janela mais curta.

O Claude Science foi lançado em 30 de junho de 2026. É uma nova categoria de produto da Anthropic — não é uma feature do Claude, é uma plataforma separada, da mesma forma que o Claude Code é separado do Claude padrão.

Pensa assim: se o Claude Code é para engenheiros de software, o Claude Science é para cientistas.

## Bloco 1 — O Que é o Claude Science (2min–5min)

**[Título de seção: "O que é o Claude Science?"]**

### A bancada de laboratório digital

O Claude Science integra, num único ambiente, tudo o que um pesquisador de ciências biológicas, químicas ou biomédicas normalmente usa em ferramentas separadas:

- **PubMed** — consulta de publicações científicas
- **Jupyter** — execução de código Python
- **R** — análise estatística
- **60+ bancos de dados científicos pré-configurados**, incluindo:
  - Bancos de dados genômicos (sequenciamento, variantes)
  - Bancos de dados proteômicos (estruturas de proteínas)
  - Quimioinformática (estruturas moleculares, propriedades químicas)
  - Dados biomédicos

### O que você consegue fazer

1. **Consultar literatura** e ter o Claude sintetizando achados de múltiplos artigos simultaneamente
2. **Executar análises** de dados genômicos ou proteômicos com código gerado pelo Claude, com rastreabilidade completa (resultado → código → fonte)
3. **Criar figuras** prontas para publicação: renderização 3D de proteínas, trilhas de navegadores genômicos, diagramas de química
4. **Redigir manuscritos** com templates para as principais revistas (Scielo, Nature, Science, Cell)
5. **Gerenciar o workflow** de pesquisa — do dado bruto ao rascunho de artigo, sem sair da plataforma

### Para quem funciona (e para quem não funciona)

**Funciona bem**: biologia molecular, genômica, proteômica, quimioinformática, biomedicina, farmacologia computacional.

**Fora do escopo desta versão**: física, matemática pura, ciências sociais, humanidades. A Anthropic deixou claro que a priorização é ciências da vida.

### Onde acessar

Disponível agora para os planos **Pro** (US$ 20/mês), **Max**, **Team** e **Enterprise**.

A Anthropic vai selecionar **até 50 projetos** para receber **até US$ 30.000 em créditos** do Claude Science cada. Além disso, a empresa Modal vai conceder até **US$ 2.000 em compute** para os projetos selecionados.

### O cronograma

| Data | O que acontece |
|------|---------------|
| **15 de julho de 2026** | Prazo final de inscrição |
| **31 de julho de 2026** | Anúncio dos projetos selecionados |

| **1 de dezembro de 2026** | Término do período de financiamento |

### Critérios de seleção (o que sabemos)

A Anthropic está priorizando:
- Pesquisa em **biologia e ciências biomédicas**
- Projetos com potencial de **impacto mensurável** (não só publicação acadêmica)
- Pesquisadores que já têm uma pergunta científica clara e dados iniciais
- Universidades públicas e privadas, institutos de pesquisa (Fiocruz, Embrapa, Butantan, Incor, CROs)

### Como se inscrever

Acesse: **anthropic.com/claude-science** → seção "AI for Science Program"

Você vai precisar:
- Descrever o projeto científico (problema, metodologia, impacto esperado)
- Indicar a instituição afiliada
- Mostrar por que o Claude Science especificamente acelera sua pesquisa

**Dica prática**: o fator diferenciador é mostrar que você tem um dado concreto que quer analisar agora, não uma ideia vaga. "Quero analisar 50.000 sequências genômicas de soja para identificar variantes associadas à resistência à seca" é melhor que "quero pesquisar agtech".

## Bloco 3 — A Oportunidade de Micro SaaS Que Ninguém Está Vendo (9min–13min)

**[Título de seção: "O ângulo de negócio"]**

Agora vem a parte que eu acho mais interessante para quem não é pesquisador mas quer construir um negócio.

O Claude Science é uma plataforma poderosa. Mas ela é uma plataforma geral — não foi construída para resolver os problemas específicos de CROs brasileiras, ou para integrar com o DATASUS, ou para automatizar o fluxo de manuscritos para o Scielo.

Isso cria três nichos de micro SaaS concretos:

### Nicho 1: Wrapper Claude Science para CROs pequenas e médias

**O problema**: Organizações de Pesquisa Clínica (CROs) brasileiras processam centenas de protocolos de pesquisa por ano. Análise de literatura, comparação de endpoints, extração de dados de artigos — tudo feito manualmente.

**A solução**: wrapper especializado em farmacologia clínica sobre o Claude Science, com templates para protocolos de pesquisa e relatórios regulatórios (ANVISA).

**Modelo de preço**: R$ 299–599/mês por pesquisador. O mercado farmacêutico brasileiro movimentou R$ 80 bilhões em 2025, com CROs crescendo 18% ao ano.

### Nicho 2: Integração com bases brasileiras (DATASUS, Sinan, Embrapa)

**O problema**: pesquisadores de saúde pública e agronegócio trabalham com dados do DATASUS, Sinan (notificações de doenças), SIM (mortalidade), Embrapa e Conab — mas o Claude Science não tem essas bases pré-configuradas.

**A solução**: conector MCP que conecta o Claude Science às principais bases de dados públicas brasileiras, com normalização de formatos e geração automática de tabelas epidemiológicas.

**Modelo de preço**: R$ 199–399/mês por laboratório. Barreira de entrada: conhecimento da estrutura das bases brasileiras (que os gringo não têm).

### Nicho 3: Automação de manuscritos científicos

**O problema**: escrever um artigo científico — mesmo com os dados prontos — leva semanas de formatação, ajuste de citações e adequação ao template da revista.

**A solução**: agente especializado que pega seus dados e análises, identifica a revista mais adequada, aplica o template correto (Scielo, Nature, NEJM, Cell) e gera o rascunho estruturado com seções padronizadas.

**Modelo de preço**: R$ 49–99/mês por pesquisador. Mercado: todas as universidades públicas brasileiras + Fiocruz + Embrapa + Butantan.
