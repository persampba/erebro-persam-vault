## Bloco 1 — O que o Claude Science faz (2min–6min)

### A analogia certa

Pensa assim: Claude Code está para engenharia de software como Claude Science está para pesquisa científica.

Claude Code automatiza o ciclo de desenvolvimento: escreve código, testa, encontra bugs, otimiza.

Claude Science automatiza o ciclo de pesquisa: coleta dados, analisa, gera hipóteses, visualiza resultados, ajuda a redigir seções de artigo.

### Capacidades verificadas

**1. Automação de tarefas de biologia e química**

O Claude Science pode executar tarefas que antes exigiam software especializado separado:
- Predição de estruturas de proteínas
- Análise de sequências genômicas
- Representações de estruturas químicas
- Simulações de reações

**2. Integração com 60+ bancos de dados científicos**

Os bancos já estão pré-configurados. Não precisa criar pipeline de dados, não precisa integração manual. Os domínios cobertos incluem:
- Genômica
- Química computacional
- Biologia estrutural

Você pergunta. O modelo consulta o banco correto e traz a resposta com visualização.

**3. Geração de visualizações científicas**

O Claude Science gera:
- Estruturas tridimensionais de proteínas
- Mapas genômicos
- Representações químicas interativas

Isso elimina o trabalho de exportar dados para ferramentas de visualização separadas — etapa que toma horas em laboratórios sem equipe dedicada.

**4. Suporte à redação científica**

O modelo pode ajudar a redigir seções de artigos, resumir achados e estruturar discussões — com base nos dados que ele próprio analisou na mesma sessão.

## Bloco 2 — Por que isso importa para o Brasil (6min–10min)

### O contexto brasileiro

O Brasil é hoje um dos maiores produtores científicos em agropecuária do mundo. A Embrapa, o IAC, dezenas de universidades federais e estaduais têm laboratórios que trabalham com genômica de plantas, biologia do solo, química de defensivos e biotecnologia.

Mas o gargalo histórico é sempre o mesmo: equipes pequenas, financiamento limitado, infraestrutura de dados fragmentada.

Um pesquisador de mestrado ou doutorado gasta em média 40–60% do tempo em coleta e tratamento de dados — antes de chegar à análise que realmente importa.

O Claude Science não resolve o problema de financiamento. Mas pode comprimir esse ciclo drasticamente.

### O ângulo de oportunidade para founders

Além dos pesquisadores, o Claude Science abre um espaço para um nicho de micro SaaS que ainda não existe bem no Brasil: **ferramentas verticais de deep tech para pesquisa aplicada**.

Pensa nos nichos concretos:
- **Agtech:** ferramenta para análise de resistência de variedades de soja usando genômica — mercado enorme, nenhuma solução acessível para pesquisadores independentes
- **Biotech:** predição de toxicidade de compostos para validação rápida antes de testes em laboratório
- **Química verde:** análise de rotas de síntese com menor impacto ambiental

Um founder com acesso ao Claude Science e ao plano de créditos da Anthropic pode construir um MVP vertical em semanas — com 60+ bancos de dados já integrados no motor.
