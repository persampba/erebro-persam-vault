## Bloco 1 — Claude Fable 5: O Que Mudou de Verdade (2min–4min30s)

> **[Tom analítico, pode usar tela de comparação ou B-roll de interface]**

### O que é o Fable 5

Claude Fable 5 é o novo modelo topo de linha da Anthropic para uso geral. Eles descrevem como "classe Mythos tornado seguro para o público" — o que já te diz muito sobre o nível de capacidade.

### O que ele faz melhor

Quatro áreas onde ele manda:

**1. Engenharia de software** — ele não só escreve código, ele raciocina sobre arquitetura, encontra bugs em contexto longo e propõe refatorações que fazem sentido.

**2. Pesquisa científica** — leitura e síntese de papers, identificação de lacunas, geração de hipóteses. Pesquisadores já estão usando como colaborador, não só como assistente.

**3. Visão** — análise de imagens, diagramas, mockups. Manda um wireframe desenhado à mão e ele vira código.

**4. Trabalho de conhecimento geral** — análise de documentos longos, síntese de informações de múltiplas fontes, planejamento estratégico.

### O preço

$10 por milhão de tokens de entrada e $50 por milhão de tokens de saída. Pra quem usa via API em volume, isso começa a ficar relevante. Pra uso pessoal, o Claude.ai ainda vai ser o caminho.

### O Mythos 5

Paralelo ao Fable 5, existe o Mythos 5 — mesmo modelo base, mas com algumas proteções removidas para um grupo muito restrito: ciberdefesores e provedores de infraestrutura crítica. A Anthropic descreve como o modelo com as capacidades de cibersegurança mais fortes do mundo. Esse não está disponível para o público geral.

> **[Pausa]**

Mas o Fable 5, apesar de ser impressionante, é "só" um modelo. O Claude Tag é uma outra história.

## Bloco 2 — Claude Tag: Funcionário de IA no Slack (4min30s–7min)

> **[Tom demonstrativo, use print/screen do Slack se possível]**

### O que é o Claude Tag

Claude Tag é uma ferramenta que vive dentro do Slack. Você não precisa abrir nenhum outro app, nenhuma interface separada.

Funciona assim: você digita uma tarefa em linguagem natural numa mensagem do Slack, marca **@Claude**, e ele começa a trabalhar. Ele decompõe sua solicitação em etapas e vai executando cada uma, respondendo numa thread com o que foi criado.

### Na prática, o que isso significa

Imagina que você precisa pesquisar concorrentes, montar uma tabela comparativa e redigir um relatório executivo. Você mandaria três mensagens diferentes pra três pessoas diferentes — ou ficaria fazendo tudo você mesmo.

Com o Claude Tag: você escreve isso uma vez no Slack, em linguagem normal, e ele executa as etapas na sequência, usando as ferramentas que você deu acesso a ele.

### Quem tem acesso

Por enquanto, está em **beta fechado** para planos Claude Enterprise e Team. Não é pra qualquer usuário ainda — mas a direção é clara.

### Por que isso importa

A Anthropic está se posicionando não só como provedor de modelo, mas como provedor de infraestrutura de trabalho. Claude Tag não é um chatbot que você consulta — é um agente que você delega.

Isso muda completamente a relação das empresas com IA: de "ferramenta que ajuda" para "membro de equipe que executa".

## Bloco 3 — O Que Isso Significa Pra Você (7min–9min30s)

> **[Tom direto, voltado para o espectador criador/empreendedor]**

### Se você é criador de conteúdo

O Fable 5 melhora tudo que você já usa no Claude: roteiros mais estruturados, pesquisa mais profunda, revisão de copy mais precisa.

O Claude Tag é interessante se você tem uma equipe — mesmo pequena. Em vez de mandar mensagem pra alguém fazer uma pesquisa, você delega pro Claude no próprio Slack da equipe.

### Se você tem um negócio ou micro SaaS

Esse é o cenário mais interessante. O Claude Tag transforma o Slack — que muitas empresas já usam como hub central — num ambiente onde IA executa tarefas reais, não só responde perguntas.

Pensa em atendimento, qualificação de leads, geração de relatórios, pesquisa de mercado. Tudo isso pode virar delegação via Slack.

### Se você é desenvolvedor ou trabalha com tecnologia

O Fable 5 via API é a ferramenta mais capaz que existe hoje para automações complexas, geração de código com raciocínio e análise de sistemas. Vale fazer testes comparativos com o que você usava antes.

### O contexto maior

A Anthropic também anunciou que o Claude está disponível no Apple Foundation Models — iOS 27, macOS 27. Isso significa que o modelo vai estar nativamente nos dispositivos Apple, integrado direto no sistema operacional.

Estamos entrando numa fase onde IA não é mais um app separado. É infraestrutura.
