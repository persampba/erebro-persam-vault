## Introdução (30s–2min)

Você já usou o Canva? Provavelmente sim. É a ferramenta de design mais popular do mundo para quem não é designer — 135 milhões de usuários ativos, 177 países.

Agora pergunta: o que essas duas ferramentas têm em comum?

Resposta: as duas exigem que você aprenda a operar uma interface. Templates, layers, frames, componentes, grids. Mesmo o Canva — que foi construído para ser simples — tem uma curva de aprendizado real.

Você não opera uma interface. Você **conversa** com o Claude e ele constrói o design por você. Você descreve o que precisa, ele entrega uma primeira versão, você refina em linguagem natural. E quando ficou certo, você exporta direto para Canva, PDF, PowerPoint ou HTML.

Mas espera — isso não é só mais um gerador de conteúdo com layout? Não. E hoje eu vou te mostrar exatamente por que não.

## Bloco 1 — O Que É o Claude Design e Por Que É Diferente (2–5min)

### A diferença fundamental

Todo gerador de design com IA que você já viu funciona assim: você dá um prompt, ele gera uma imagem ou um layout estático, você aceita ou descarta.

O Claude Design é diferente por três razões estruturais:

**1. É uma sessão, não uma geração**

Você não gera e descarta. Você conversa. O Claude mantém contexto ao longo da sessão — lembra que você pediu "minimalista", lembra que você disse "não quero mais de 3 cores", lembra que o slide 2 precisa ter mais texto que os outros. Isso não é filtro de estilo. É memória de projeto.

**2. Ele consome o seu design system**

Você pode importar o design system da sua empresa — cores, tipografia, componentes, espaçamentos — e o Claude aplica automaticamente a cada projeto. O output não é "bonito genérico". É "bonito e consistente com a marca que você já tem".

**3. Round-trip com código**

O design que o Claude Design gera pode ser mandado diretamente para o Claude Code. Sem exportar SVG, sem copiar código, sem abrir outra ferramenta. A pipeline Design → Code → Deploy da Anthropic começa a funcionar como fluxo real para quem usa ambos.

### Quem é o público-alvo

O Claude Design não foi feito para substituir o Figma em times de design enterprise. Foi feito para:

- **Solopreneurs** sem designer que precisam de apresentações, landing pages e materiais de pitch com aparência profissional
- **Founders em estágio inicial** que não têm budget para designer mas têm que mostrar o produto para investidores
- **Criadores de conteúdo** que fazem slides de carrossel, thumbnails diferenciadas e one-pagers de parceria
- **Consultores** que entregam relatórios visuais para clientes e perdiam horas no PowerPoint

## Bloco 2 — Como Funciona na Prática (5–8min)

### O fluxo completo

**Passo 1 — Entrada**

Você pode começar de três formas:
- Prompt de texto puro: "Crie um deck de pitch de 8 slides para um micro SaaS de gestão de MEI, público: investidores anjo BR, tom: confiante e direto"
- Upload de documentos: DOCX, PPTX, XLSX — o Claude lê o conteúdo e cria o visual
- Captura web: você aponta a ferramenta para o seu site e o Claude extrai elementos visuais e de copy diretamente

**Passo 2 — Refinamento por conversa**

Primeira versão entregue. Agora você refina em linguagem natural:
- "O slide de problema precisa de um dado numérico em destaque"
- "Troca o azul por verde-escuro, mais próximo do meu logo"
- "Esse gráfico está confuso, simplifica para dois valores só"

Cada instrução é aplicada mantendo o contexto do projeto inteiro. O Claude não "reseta" o entendimento a cada mensagem.

**Passo 3 — Sliders personalizados**

Para ajustes recorrentes (como proporção texto/imagem ou intensidade de cor), o Claude cria controles deslizantes personalizados para você ajustar visualmente em vez de descrever em palavras. Detalhe sofisticado que revela que o produto foi pensado para iteração real, não para demonstração.

**Passo 4 — Exportação**

Quando ficou certo:
- Canva (para quem já usa o ecossistema)
- PDF (para envio direto)
- PPTX (para editar no PowerPoint)
- HTML standalone (para hospedar como landing page)
- URL interna (para compartilhamento dentro da organização sem exportar)

### O que o Claude Design não é

Não é gerador de imagem. Ele não cria ilustrações ou fotografia sintética — para isso você continua usando Midjourney, DALL-E ou Firefly. O Claude Design trabalha com layout, tipografia, estrutura de informação e visualização de dados. Elementos visuais complexos você importa de outras fontes.

## Bloco 3 — A Suite Anthropic: Design → Code → Deploy (8–11min)

### A jogada estratégica que ninguém está discutindo

O Claude Design não é um produto isolado. É uma peça de uma arquitetura que a Anthropic vem construindo desde 2024:

**Claude Design** → você cria o visual do produto
**Claude Code** → você constrói o produto
**Claude Cowork** → você gerencia o projeto e a equipe
**Deploy** → você publica

Para um solopreneur, isso significa: em 2026, é tecnicamente possível ir de ideia a produto publicado sem contratar designer, dev, gerente de projeto ou copywriter. Não perfectamente. Não sem trabalho. Mas é possível.

A Anthropic claramente quer ser o sistema operacional do solopreneur.

### Comparação direta: quando usar o quê

| Situação | Ferramenta certa |
|----------|-----------------|
| Deck de pitch para investidor | Claude Design (velocidade + coerência com brand) |
| Interface de produto para cliente | Figma (colaboração com times de design) |
| Post de carrossel para Instagram | Canva (templates rápidos, ecossistema social) |
| Landing page do micro SaaS | Claude Design → Claude Code (round-trip sem fricção) |
| Apresentação interna semanal | Claude Design (velocidade, sem template hunting) |
| Identidade visual do zero | Profissional de design (criatividade estratégica > velocidade) |

A regra prática: se você está criando para comunicar e não para emocionar visualmente, o Claude Design é mais rápido e mais consistente que o Canva. Se você precisa de criatividade visual como diferencial da marca, ainda precisa de um designer humano.
