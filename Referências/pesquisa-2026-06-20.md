## Destaques do Dia

### 1. Claude Code Artifacts — Dashboards ao Vivo (18/06, 2 dias atrás)
A Anthropic lançou em **beta em 18/06** o Claude Code Artifacts para planos Team e Enterprise. A novidade transforma sessões de Claude Code em páginas HTML privadas que atualizam em tempo real quando o agente publica mudanças — o mesmo link, sem recriar documento. Devs conectam fontes de dados ao vivo e enviam o link para o time ver atualizar em tempo real. Cada mudança cria versão restaurável. Por default é privado, não pode ser publicado para a internet.

Em **15/06**, a Anthropic também separou o faturamento: uso programático (agentes, CI/CD, SDK) agora é cobrado diferente do uso interativo (humanos digitando prompts). Impacto direto para founders de micro SaaS que usam a API em automações.

**Ângulo para vídeo:** "Claude Code Artifacts: Seu Código Agora É um Dashboard ao Vivo — O Que Isso Muda Para Devs e Empresas"
- Evento < 48h, zero PT-BR de qualidade
- Impacto prático: founder mostra ao cliente um link que atualiza sozinho
- Conecta com mudança de faturamento de 15/06 (contexto de custo)

### 2. Fable 5 e Mythos 5 — Banidos, KYC em 18 Dias (12/06–atual)
O governo americano (administração Trump) emitiu diretiva de exportação em **12/06** bloqueando Fable 5 e Mythos 5 para estrangeiros. Sem mecanismo de verificação de nacionalidade em tempo real, a Anthropic derrubou ambos globalmente. A verificação de identidade (KYC) obrigatória começa em **8/07** (18 dias a partir de hoje). Especulações de retorno circulam; a Anthropic descreveu como "mal-entendido" e contesta judicialmente.

**Ângulo para vídeo:** "Fable 5: Quando Volta e o Que Você Precisa Fazer Antes de 8 de Julho"
- KYC em 18 dias = urgência concreta
- Cobertura BR existente só cobre o "o quê" — zero sobre "e agora, o que fazer"

- **87% dos criadores** usam ferramentas de IA (ante 61% há 3 anos)
- Criadores economizam **média de 3 horas por peça de conteúdo** com IA
